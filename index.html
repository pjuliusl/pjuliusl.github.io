Projetos

ia / mlops

Fine-tuning e avaliação de modelos de decisão

Montei o pipeline de fine-tuning LoRA de um modelo que classifica registros em quatro categorias. Agrupo as partições por registro para que o mesmo caso não apareça no treino e no teste. O treino roda como Job em GPU no Kubernetes, com checkpoints e retomada, e o MLflow guarda parâmetros e métricas. Escolho o checkpoint pelo limite de erros graves e, na exportação, comparo as respostas do treino com as da inferência antes de liberar a versão.

PyTorch · Transformers · PEFT · MLflow · K3s

ia / integração

Assistente analítico MCP no Apache Superset

Escrevi em Python o MCP Host e o Client que ligam um assistente ao Superset. O servidor confere tokens JWT/JWKS, escopos e o catálogo de ferramentas. O chat abre dentro do dashboard com proteção CSRF, e cada usuário e aba ganha sessão e nonce próprios no Redis/Sentinel.

Python · MCP · Superset · Redis · Jenkins

ia / avaliação humana

Plataforma de revisão humana de respostas de IA

Analistas revisam respostas sem saber se vieram do modelo ou de outro analista. A plataforma tem fila de trabalho, justificativa em cada decisão e histórico das revisões. Os painéis mostram concordância, erros graves, cobertura e confiança. O login usa Argon2id e trava depois de tentativas repetidas.

FastAPI · SQLAlchemy · PostgreSQL · Alembic

ia / conversação

Assistente de registro de ocorrências

Um motor de regras confere o que falta no relato e se o caso pode ser registrado pela internet. Um LLM escolhe a próxima pergunta e redige a narrativa, e o motor recusa fatos que o cidadão não contou. Se o relato indica risco imediato, o assistente orienta ligar para o 190. A cada commit, cidadãos simulados conversam com o assistente e um avaliador compara o resultado com o gabarito.

FastAPI · LLM · LiteLLM · pytest

ia / fork de projeto open source

Chat Infinito, um fork do UniiChat

O UniiChat, de Victor Taelin, é um chat que não termina: guarda a conversa inteira numa árvore de resumos e reabre os trechos antigos quando precisa. No meu fork, troquei as chaves de API pelas assinaturas Claude e ChatGPT, chamando os clientes oficiais claude e codex. O Codex gera os resumos em lote e, quando um plano bate o limite, outro modelo assume. Acrescentei busca exata no histórico, uma regra que mantém links e números nos resumos e o uso real das assinaturas na tela.

TypeScript · Bun · Claude Code · Codex CLI · MCP
